# Product Overview

STEELO 稼働照合・ドライバー支払明細システムは、軽貨物運送業を営むSTEELOの
業務基幹システム。元請け（BOND's株式会社）が発行する月次支払明細Excelと、
LINEグループに流れる配車メッセージを自動照合し、計上漏れ・金額相違を検出した上で、
ドライバー約20名分の支払明細Excelを自動生成する。

ベースは LINE Harness OSS（line-oss-crm）。元のCRM/マーケティングオートメーション機能は
維持しつつ、運送業向けの「配車記録蓄積 → 元請けExcel照合 → 支払明細出力」フローを追加実装する。

## Core Capabilities

- **LINEメッセージ自動蓄積**: 約20のドライバー別LINEグループから配車メッセージ・完了報告を
  Webhook受信し、グループ名（「{名前}DR ...」）でドライバー紐付け
- **配車メッセージ構造化**: Claude Haiku APIで配車メッセージを案件レコードに自動解析
  （Phase 2）
- **元請けExcelインポート**: BOND'sから月次で届く支払明細Excelをアップロード・取り込み、
  ヘッダーサマリーと明細行を分離保存
- **自動照合エンジン**: LINE配車レコードと元請けレコードを日付/ドライバー/業務名でマッチング、
  3分類（matched / client_only / dispatch_only）で差分検出（Phase 2）
- **ドライバー支払明細生成**: 手数料控除(×0.925) → インボイス有無で消費税分岐(×1.1) →
  端数四捨五入の計算ロジックで、ドライバー別Excelを個別 or ZIP一括出力

## Target Use Cases

- **管理者（STEELO代表 1名）**: 月初に元請けExcelを取り込み、照合結果を確認し、
  ドライバー支払明細を生成。Webブラウザから管理画面で操作
- **ドライバー（約20名）**: LINEで配車を受信・完了報告するだけ。システム自体は使わない
- **元請け（BOND's 1社）**: 配車メッセージをLINEで送信、月次でExcel明細を発行

## Value Proposition

現在月1,000件規模の照合・支払明細作成が全て手作業で行われており、
請求漏れリスクと作業負荷が高い。本システムは:

- 配車レコードの欠落（=元請けへの請求漏れ）を自動検出し、売上機会損失を防ぐ
- インボイス有無による消費税分岐を含む支払計算を自動化し、計算ミスを撲滅
- 月次作業を数日から数時間に短縮

低運用コスト（Cloudflare Workers + D1 + Claude Haiku で月¥500〜1,500）で
1人企業でも持続可能な業務基幹を実現する。
